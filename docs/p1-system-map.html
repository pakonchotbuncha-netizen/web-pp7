🔄 5 ขั้นตอน P1 — Process Detail

Step 1 — ขออัตรากำลัง
WI: WI-001, P1_HC-001
DB: headcount_requests
UI: p1-headcount.html

Input: ความต้องการ BU Output: HC approved

Dept Head สร้างคำขอ → ระบุ ตำแหน่ง/ระดับ/งบประมาณ → ผู้อนุมัติ approve
Step 2 — เปิดรับสมัคร
WI: WI-001 (ต่อเนื่อง)
DB: headcount_requests → job_posting
UI: p1-headcount.html

Input: HC approved Output: Job Post

สร้าง Job Posting → เลือกแหล่งรับสมัคร → เผยแพร่ QR / Job Board
Step 3 — รับใบสมัคร
WI: WI-002 (รับใบสมัคร)
DB: candidates, recruitment_sources
UI: p1-candidates.html

Input: ใบสมัคร PKG Output: candidate record

ผู้สมัครกรอก QR Form → บันทึก PDPA → stage: screening
Step 4 — คัดเลือก
WI: WI-002
DB: candidates (stage update)
UI: p1-candidates.html

Input: candidate data Output: stage→offer

screening → phone_screen → interview → assessment → offer
Step 5 — สรุปผล + บรรจุ
WI: WI-003, WI-011
DB: candidates → employees
UI: p1-candidates.html

Input: offer accepted Output: employee

Offer accepted → สร้าง employee record → ส่งต่อ P4

📊 Data Flow Diagram

Step Input Process Output
1. ขออัตรา ความต้องการ BU/Dept, งบประมาณ สร้าง HC Request → อนุมัติ headcount_requests (approved)
2. เปิดรับ HC Request (approved) สร้าง Job Posting + เลือกแหล่ง Job Post published + recruitment_sources
3. รับใบสมัคร ใบสมัคร PKG, Resume, PDPA consent สร้าง Candidate record candidates (stage: screening)
4. คัดเลือก Candidate data, ผลสัมภาษณ์ Stage advancement / rejection candidates (stage: offer / rejected)
5. สรุปผล Candidate (offer), HC Request สร้าง Employee record employees (new) → P4

Pipeline Stages:

screening → phone_screen → interview → assessment → offer → hired │ ↘ rejected
