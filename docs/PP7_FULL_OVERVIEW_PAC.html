🧲 P1 แสวงหา

📌 เดิม: HR อ่านใบสมัครเอง, โพสต์ทีละช่องทาง, คัดเลือกด้วยดุลยพินิจ
🤖 AI: วิเคราะห์คำขอ + Auto-Post + Screening ให้คะแนน + แจ้งผลอัตโนมัติ

🎯 P2 หยั่งประเมิน

📌 เดิม: คณะกรรมการตั้งคำถามเอง, ประเมินด้วยความรู้สึก
🤖 AI: แนะนำคำถาม CC1-CC7 + วิเคราะห์คำตอบ + สรุปคะแนนอัตโนมัติ

🤝 P3 จับคู่คนกับงาน

📌 เดิม: จับคู่จากดุลยพินิจ, ส่งต่อ BU ด้วยเอกสาร
🤖 AI: Matching 50/30/20 + หา BU เหมาะสุด + Talent Pool

📈 P4 ประเมินผล

📌 เดิม: ประเมินด้วยความรู้สึก, สรุปผลช้า
🤖 AI: วิเคราะห์ 360° + จับ bias + แปลงเป็นข้อมูลเชิงประจักษ์

🎓 P5 พัฒนา (พี่เลี้ยง)

📌 เดิม: PAD ตรวจข้อมูล 3 วัน, นับวินัยเอง, 4C ตัดสินเอง
🤖 AI: ตรวจข้อมูล flag + Line Bot รับ DTA + AI Coach + วินัย 80% + ใบเหลือง/แดง

💰 P6 ค่าตอบแทน

📌 เดิม: คีย์เอง, คำนวณ Excel, ตรวจด้วยสายตา
🤖 AI: ดึงเหตุการณ์ P1/P3 + คำนวณภาษี + ตรวจ anomaly + e-slip + กระทบยอด

🌿 P7 คุณภาพชีวิต

📌 เดิม: ดูแลตามเหตุการณ์, ตอบคำถามซ้ำ
🤖 AI: Wellbeing Tracker + Chatbot HR 24 ชม. + วิเคราะห์ Engagement

📊 ตารางสรุป AI Touchpoints ทั้งระบบ (22 จุด)

Pขั้นกระบวนการเดิม🤖 AI เข้ามาช่วยระดับ
P11แจ้งขออัตรากำลังAI วิเคราะห์คำขอ + เช็คอัตราซ้ำสูง
P13ประกาศรับสมัครAI Auto-Post + Tracking ช่องทางกลาง
P14.2คัดเลือกใบสมัครAI Screening ให้คะแนนอัตโนมัติสูง
P27สัมภาษณ์/ทดสอบAI แนะนำคำถาม CC + วิเคราะห์คำตอบสูง
P38จับคู่คนกับงานAI Matching Engine (50/30/20)สูง
P3—ส่งต่อ BU อื่นAI หา BU เหมาะสุด + ติดตามอัตโนมัติกลาง
P4—ประเมิน 360°AI วิเคราะห์ + จับ biasสูง
P521set ระบบพี่เลี้ยง ตรวจ 3 วันAI ตรวจข้อมูล + flag ไม่ครบสูง
P522สร้างช่องทาง Line/E-mailAI ส่งข้อความแจ้ง + ติดตามกลาง
P523น้องเลี้ยงรายงาน DTALine Bot รับรายงาน + แยกหมวดสูง
P524พี่เลี้ยง CoachAI สรุปประเด็น + แนะนำหัวข้อสูง
P525ตรวจวินัย ≥ 80%AI คำนวณ + เตือนก่อนหลุดสูง
P5264C ใบเหลือง/แดงAI เสนอระดับใบ + ร่างประกาศกลาง
P527ตรวจวินัย CoachAI เตือนพี่เลี้ยงไม่ครบกลาง
P529สรุปประเมิน + ปรับปรุงAI วิเคราะห์ sentimentกลาง
P630เพิ่มสมาชิก PayrollAI ดึงเหตุการณ์ P1/P3สูง
P631-32เตรียมข้อมูล + คำนวณภาษีAI ดึงรายได้ + คำนวณภาษี/สปส.สูง
P633ตรวจสอบเงินเดือนAI ตรวจ anomalyสูง
P634e-slip + ส่ง LineAI สร้างสลิป + รับแจ้งผิดสูง
P635-36ปริ้น VC + การเงินตรวจAI สร้างกระทบยอด + flag ผลต่างกลาง
P637PAO ตั้งโอนเงินAI เตรียมไฟล์โอน + ตรวจซ้ำสูง

#หลักการรายละเอียด
1AI แนะนำ / มนุษย์ตัดสินใจAI ช่วยร่าง/เตือน/คำนวณ แต่การตัดสินใจสุดท้ายอยู่ที่คน (PAD/HR/การเงิน)
2ข้อมูลไหลข้ามขั้นตอนP1→P2→P3→P4→P5→P6/P7 ข้อมูลไหลต่อเนื่อง ไม่ต้องคีย์ซ้ำ
3ลดงาน Manual ≥ 60%งานที่ทำซ้ำๆ ทุกเดือน ให้ AI ทำแทน
4ลด Human Error ≥ 80%AI ตรวจ anomaly ก่อนจ่าย/ก่อนประกาศ
5Audit Log 100%ทุกการตัดสินใจของ AI + มนุษย์ บันทึกย้อนกลับได้
