ตารางจุด AI — P1

รหัสจุด AIInput → Outputคนตัดสินสถานะ
A1AI ตรวจความครบฟอร์ม + PDPA Gateฟอร์มใบสมัคร → ผ่าน/ไม่ผ่าน (ขาดช่องไหน)ระบบกันอัตโนมัติ (PDPA ต้อง True)ทำแล้ว (Task 3)
A2AI OCR/Parser ดึงข้อมูลเอกสารบัตรปชช / ทะเบียนบ้าน / วุฒิ / CV → ข้อมูลลงฟอร์มอัตโนมัติผู้สมัครยืนยันข้อมูลทำแล้ว (Task 3)
A3AI แปล 3 ประเทศใบสมัคร TH/LA/KH → แปลข้ามภาษาอัตโนมัติHR ตรวจทานทำแล้ว (Task 3)
A4AI แจ้งเตือน + จัดหมวดหมู่เบื้องต้นใบสมัครใหม่ → Telegram หา HR + แยกตามตำแหน่งHR เปิดดู Dashboardทำแล้ว (Task 3)
A5AI คัดกรองเบื้องต้น Task 4ใบสมัคร+OCR เทียบตำแหน่งที่สมัคร → คะแนน + เหตุผลรายหัวข้อ + จัดอันดับคน BMC/PAO ตัดสินร่วม (ผ่าน/รอ/ไม่ผ่าน)ออกแบบแล้ว +3 วันทำการ
A6AI แนะนำตำแหน่งทางเลือก (ใหม่ 3 ต.ค. 69)คุณสมบัติผู้สมัคร เทียบตำแหน่งว่างทั้งหมดที่เปิดอยู่ → Top-N ตำแหน่งที่เหมาะกว่า + เหตุผลรายตำแหน่ง → เป็นตัวเลือกให้ผู้สมัครตัดสินใจคน ผู้สมัครเลือกเอง + HR/BMC/PAO ยืนยัน (ตรงสาย→P2 / เลือกใหม่→P2 / ไม่ผ่าน→ปิด)ออกแบบแล้ว (สั่งพี่ปกรณ์ 3 ต.ค. 69)

ตารางจุด AI — P2

รหัสจุด AIInput → Outputคนตัดสินสถานะ
B1AI สร้างชุดคำถามราย CC (5.1)ตำแหน่ง + CC ที่ต้องการ → ชุดคำถามสัมภาษณ์ราย CC1–CC7กรรมการเลือก/ปรับคำถามPhase 2 (1 วัน)
B2AI วิเคราะห์บันทึกสัมภาษณ์ (5.2)บันทึกสัมภาษณ์ → คะแนนราย CC + หลักฐานอ้างอิงกรรมการยืนยันคะแนนPhase 2 (1.5 วัน)
B3AI สรุป CMC/ทัศนคติ + Cross-check P1 (5.3)ผล CMC + ทัศนคติ + ข้อมูล P1 → โปรไฟล์ + ธงขัดแย้งกรรมการพิจารณาธงPhase 2 (0.5 วัน)
B4AI ร่างรายงานสรุป P2 (5.4)คะแนนทั้งหมด → รายงานสรุป + Recommendation + Auditคน BMC/PAO ตัดสินสุดท้ายPhase 2 (1 วัน)
B5AI แนะนำบทบาทใหม่ที่เหมาะกว่า (ใหม่ 3 ต.ค. 69)หลังให้คะแนนสัมภาษณ์: AI ประมวลว่าเหมาะกับตำแหน่งที่สัมภาษณ์หรือไม่ + เทียบตำแหน่งว่างทั้งหมด → Top-N บทบาทใหม่ที่เหมาะกว่า + เหตุผล → ทีมสัมภาษณ์พิจารณาจากคำแนะนำ AIคน ทีมสัมภาษณ์/BMC/PAO ตัดสิน (ตรงสาย→P3 / บทบาทใหม่→P3 / ไม่ผ่าน→ปิด)Phase 2 (สั่งพี่ปกรณ์ 3 ต.ค. 69)

หลักการ — AI เสนอ / คนตัดสิน

ใช้เหมือนกันทุก P · กัน AI ตัดสินคนเดียว

ข้อหลักการรายละเอียด
1AI ช่วยคัด–วิเคราะห์–สรุปAI ทำหน้าที่เตรียมข้อมูลพร้อมตัดสิน (คะแนน + เหตุผล + หลักฐาน) ไม่ตัดสินแทนคน
2คนตัดสินสุดท้ายเสมอP1: HR/BMC/PAO (+ผู้สมัครเลือก) · P2: BMC/PAO + ทีมสัมภาษณ์ (จุดตัดสินสุดท้าย) · P3: ไม่ตัดสิน — บันทึกผลอย่างเดียว
3Audit 100%ทุกจุด AI เก็บ log: input → output → คนยืนยัน (P1_AIAnalysis / P2_AIAnalysis / P3_Matching)
4ข้อความภายนอกสุภาพแจ้งผลไม่ผ่านใช้ภาษาอบอุ่น ไม่ใช้ศัพท์ภายใน (P1/P2/P3/CC) — ตามรูปแบบที่กำหนด 14 ก.ค. 69
5ลำดับพัฒนาP1 Task 3 เสร็จแล้ว → Task 4 (+3 วัน, รวม A6 แนะนำตำแหน่งทางเลือก) → P3 = บันทึกผลลงฐาน (ไม่มี engine ตัดสิน) → P2 Task 5.1–5.4 + B5 Phase 2 หลัง 6 พ.ย. 69
6แนะนำตำแหน่งทางเลือก 2 ช่วง (ใหม่ 3 ต.ค. 69)P1-A6: หลังคัดกรองคุณสมบัติ เทียบตำแหน่งว่างทั้งหมด → Top-N + เหตุผล → ผู้สมัครเลือกเอง P2-B5: หลังสัมภาษณ์ให้คะแนน เทียบตำแหน่งว่างทั้งหมด + คะแนน CC → Top-N บทบาทใหม่ → ทีมสัมภาษณ์พิจารณา · ผลตัดสินจบที่ P2 แล้ว P3 บันทึกผลลงฐานเพื่อใช้ต่อใน P4–P7
