ตารางจุด AI — P1

รหัสจุด AIInput → Outputคนตัดสินสถานะ
A1AI ตรวจความครบฟอร์ม + PDPA Gateฟอร์มใบสมัคร → ผ่าน/ไม่ผ่าน (ขาดช่องไหน)ระบบกันอัตโนมัติ (PDPA ต้อง True)ทำแล้ว (Task 3)
A2AI OCR/Parser ดึงข้อมูลเอกสารบัตรปชช / ทะเบียนบ้าน / วุฒิ / CV → ข้อมูลลงฟอร์มอัตโนมัติผู้สมัครยืนยันข้อมูลทำแล้ว (Task 3)
A3AI แปล 3 ประเทศใบสมัคร TH/LA/KH → แปลข้ามภาษาอัตโนมัติHR ตรวจทานทำแล้ว (Task 3)
A4AI แจ้งเตือน + จัดหมวดหมู่เบื้องต้นใบสมัครใหม่ → Telegram หา HR + แยกตามตำแหน่งHR เปิดดู Dashboardทำแล้ว (Task 3)
A5AI คัดกรองเบื้องต้น Task 4ใบสมัคร+OCR เทียบ JOB_POSTING → คะแนน + เหตุผลรายหัวข้อ + จัดอันดับคน BMC/PAO ตัดสินร่วม (ผ่าน/รอ/ไม่ผ่าน)ออกแบบแล้ว +3 วันทำการ

ตารางจุด AI — P2

รหัสจุด AIInput → Outputคนตัดสินสถานะ
B1AI สร้างชุดคำถามราย CC (5.1)ตำแหน่ง + CC ที่ต้องการ → ชุดคำถามสัมภาษณ์ราย CC1–CC7กรรมการเลือก/ปรับคำถามPhase 2 (1 วัน)
B2AI วิเคราะห์บันทึกสัมภาษณ์ (5.2)บันทึกสัมภาษณ์ → คะแนนราย CC + หลักฐานอ้างอิงกรรมการยืนยันคะแนนPhase 2 (1.5 วัน)
B3AI สรุป CMC/ทัศนคติ + Cross-check P1 (5.3)ผล CMC + ทัศนคติ + ข้อมูล P1 → โปรไฟล์ + ธงขัดแย้งกรรมการพิจารณาธงPhase 2 (0.5 วัน)
B4AI ร่างรายงานสรุป P2 (5.4)คะแนนทั้งหมด → รายงานสรุป + Recommendation + Auditคน BMC/PAO ตัดสินสุดท้ายPhase 2 (1 วัน)

ตารางจุด AI — P3

รหัสจุด AIInput → Outputคนตัดสินสถานะ
C1AI Matching Engineโปรไฟล์ + JD + LIA → Match Score + Gap + คำแนะนำ (เหมาะสมมาก→ไม่เหมาะสม)HR ดูประกอบ + BMC อนุมัติออกแบบแล้ว (schema P3_Matching)
C2AI ตรวจประวัติ/เอกสารเบื้องต้นวุฒิ / ประวัติงาน / Reference → ผลตรวจ Pass/Fail + หมายเหตุHR ตรวจซ้ำเคสสำคัญออกแบบแล้ว
C3AI ปิดใบสมัคร / ส่งต่อข้าม BUคะแนนต่ำ → ปิด + แจ้งผลสุภาพ + Talent Pool · เหมาะที่อื่น → ใบส่งต่อคน HR ยืนยันก่อนปิดออกแบบแล้ว

หลักการ — AI เสนอ / คนตัดสิน

ใช้เหมือนกันทุก P · กัน AI ตัดสินคนเดียว

ข้อหลักการรายละเอียด
1AI ช่วยคัด–วิเคราะห์–สรุปAI ทำหน้าที่เตรียมข้อมูลพร้อมตัดสิน (คะแนน + เหตุผล + หลักฐาน) ไม่ตัดสินแทนคน
2คนตัดสินสุดท้ายเสมอP1: HR/BMC/PAO · P2: BMC/PAO + กรรมการ · P3: HR/BMC
3Audit 100%ทุกจุด AI เก็บ log: input → output → คนยืนยัน (P1_AIAnalysis / P2_AIAnalysis / P3_Matching)
4ข้อความภายนอกสุภาพแจ้งผลไม่ผ่านใช้ภาษาอบอุ่น ไม่ใช้ศัพท์ภายใน (P1/P2/P3/CC) — ตามรูปแบบที่กำหนด 14 ก.ค. 69
5ลำดับพัฒนาP1 Task 3 เสร็จแล้ว → Task 4 (+3 วัน) → P3 engine → P2 Task 5.1–5.4 Phase 2 หลัง 6 พ.ย. 69
