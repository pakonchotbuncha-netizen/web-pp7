## 3. Flow ทำงานประจำเดือน (วันที่ 1–5) แบบจับมือทำ

### ขั้นที่ 1 — ดึงข้อมูลดิบการลงเวลา (กดเอง ไม่มีอัตโนมัติ)

1. เปิด tab ของเดือนนั้น เช่น **`สค`**
2. **กดดึง/วางข้อมูล** รายงานการลงเวลารายวันลงในคอลัมน์โครงสร้างนี้ (เริ่มแถว 8 ลงไป):
   - `A timeDate` · `B EmployeeId` · `C FirstName` · `D LastName` · `E branch_ctt`
   - `F timeIN` · `G timeOut` · `H dcp_in` · `I dcp_out` · `J update_time` · `K sum`
   - (บรรทัดหัวเรื่องจริงอยู่ที่แถว 8: `timeDate / EmployeeId / FirstName / LastName / branch_ctt / timeIN / timeOut / dcp_in / dcp_out / update_time / sum`)
3. ⚠️ **ข้อมูลดิบต้องกดดึงจากระบบเอง** — ไม่มีระบบดึงอัตโนมัติ (ยืนยันแล้ว)

### ขั้นที่ 2 — เช็ค/แก้ไขที่ `สรุปรายคน_<เดือน> ...`

tab นี้คำนวณอัตโนมัติ (ARRAYFORMULA) จากข้อมูลดิบ โดยสรุปต่อ 1 คน 1 แถว:

- **ซ้าย (A:O):** ข้อมูลดิบรายบรรทัด (เข้างาน/ออกงาน/รวม/มา/ลา/ลาพักร้อน/ลากิจ/ลาป่วย/สาย/ออกก่อนเวลา/หยุดกะ)
- **ขวา (P:AY):** ตารางสรุปรายคน + คะแนน (นี่คือส่วนสำคัญ):

| คอลัมน์ | ความหมาย | สูตรหลัก |
|---|---|---|
| P–S | รหัส/ชื่อ/นามสกุล/บริษัท | UNIQUE+FILTER จากข้อมูลดิบ |
| T | BU | VLOOKUP PKGemployee |
| U | ประเทศ (ไทย/RPLC/RAFCO) | VLOOKUP config |
| V–AH | มาปกติ/หยุด/ลาพักร้อน/หยุดกะ/รวม/ลากิจ/ลาป่วย/สาย/ออกก่อน | SUMIF ตามรายการ |
| **AN** | **วันหาย** (ขาดงาน) | VLOOKUP จาก `TA_<เดือน>` คอลัมน์ F |
| **AO** | หักขาดงาน = วันหาย × **0.3** | `AN*AO4` |
| AP/AQ | ลากิจ × **0.2** | `AP*AQ4` |
| AR/AS | ลาป่วย × **0.1** | `AR*AS4` |
| AT/AU | สาย × **0.05** | `AT*AU4` |
| AV/AW | ออกก่อน × **0.05** | `AV*AW4` |
| **AX** | **รวมหักทั้งเดือน** | `AO+AQ+AS+AU+AW` |
| **AY** | **คะแนนคงเหลือ = 5 − AX** | `5-AX` |

> ค่าเต็ม/อัตราหักอยู่ใน **แถว 4** (header) เช่น AO4=0.3, AQ4=0.2, AS4=0.1, AU4=0.05, AW4=0.05, AY4=5
> สรุป: **คอลัมน์ AY = คะแนนคงเหลือของเดือน** (คือค่า 5 คะแนนหักแล้ว) ← ตัวที่ VLOOKUP ไปใช้ต่อ

### ขั้นที่ 3 — ตรวจสอบสถานะที่ `TA_<เดือน> THAI`

tab นี้แสดงผลรายบุคคล (FILTER เฉพาะ `ประเทศ="ไทย"` จาก สรุปรายคน):

| คอลัมน์ | ความหมาย |
|---|---|
| A | รหัสสมาชิก |
| B–C | ชื่อ / นามสกุล |
| D | บริษัท |
| E | **วันมาทำงาน** (VLOOKUP รวม) |
| F | **วันหาย** = `E9 − มาทำงาน − ลากิจ/วัน − หยุดกะ` |
| G | **ตรวจสอบ** — สถานะ: `ครบ` / `สมาชิกยังไม่ได้ตรวจสอบ` / `ทีมPAOแก้ไขให้วันที่ 25` |
| H | หมายเหตุ |
| J–N | ลากิจ/วัน, ลาป่วย/วัน, สาย/วัน, ออกก่อนเวลา/วัน |
| O | หยุดกะ |

**สถานะ G** สูตรจริง:
```
=IF(F=0, "ครบ", IF(F<0, "ทีมPAOแก้ไขให้วันที่ 25", "สมาชิกยังไม่ได้ตรวจสอบ"))
```
- `ครบ` = วันหายเป็น 0 → ผ่าน
- `ทีมPAOแก้ไขให้วันที่ 25` = วันหายติดลบ (มาทำงานเกิน 25) → PAO ต้องแก้
- `สมาชิกยังไม่ได้ตรวจสอบ` = วันหาย > 0 → ยังไม่ครบ

### ขั้นที่ 4 — ให้คะแนน (ไม่ต้องพิมพ์เอง คำนวณอัตโนมัติ)

คะแนนคำนวณเองจาก Step 2–3 ตามเกณฑ์ **5 คะแนน** หักปี 2026 (0.3/0.2/0.1/0.05/0.05)
หน้าจอที่ "ให้คะแนน" จริงคือ **`สรุปรายคน_<เดือน>` คอลัมน์ AX (รวมหัก) และ AY (คงเหลือ)**

### ขั้นที่ 5 — สรุปสะสมที่ `สรุปTA`

- แถว 5 = header 12 เดือน (มกราคม 2026 … ธันวาคม 2026)
- แต่ละเดือนมี 3 คอลัมน์: **หัก / คงเหลือ / ชื่อเดือน**
- คอลัมน์ A–C = รหัส/ชื่อ/นามสกุล (FILTER จาก PKGemployee)
- สูตรต่อเดือน:
  - `D` (หัก ม.ค.) = `VLOOKUP(A, 'สรุปรายคน_มค THAI'!P5:AY, 35, 0)` → ดึงคอลัมน์ AX (รวมหัก)
  - `E` (คงเหลือ ม.ค.) = `5 − D` (ผ่าน `AL−D` โดย AL = ฐาน 5)
  - เดือนถัดไป = `คงเหลือเดือนก่อน − หักเดือนนี้` (สะสมต่อเนื่อง)
- ⚠️ คะแนนสะสม **ติดลบได้** ถ้าหักรวมเกิน 5 (เงื่อนไข "ขาด ลา มาสาย = Infinity")

### ขั้นที่ 6 — แจ้ง LINE (อัตโนมัติ)

- tab **`SENTLINE_TA`** = หน้าสรุปสำหรับส่ง LINE โครงสร้างเดียวกับ `สรุปTA` แต่ filter ตาม **"เลือกBU>>>"** (dropdown เลือกกลุ่ม เช่น RPLCG)
- **ระบบส่ง LINE อัตโนมัติ** (ไม่ต้องกดส่งเอง)

### ตัวอย่างคำนวณ

| กรณี | วิธีคิด | คะแนน |
|---|---|---|
| มาครบ ไม่ขาด/ลา/สาย | 5 − 0 | **5.0** |

| ขาด 1 + สาย 1 | 5 − (0.3 + 0.05) | **4.65** |
| ลากิจ 1 + ลาป่วย 1 + สาย 3 + ออกก่อน 1 | 5 − (0.2+0.1+0.15+0.05) = 5 − 0.5 | **4.5** |

> ⚠️ หมายเหตุตัวอย่าง "ลากิจ 1 + ลาป่วย 2": ตามอัตราในชีต = 5 − (0.2 + 0.2) = **4.6**
> (โจทย์ที่พี่ปกรณ์ยกมา "= 4.7" น่าจะคิดเฉพาะ ลาป่วย 2 + ลากิจ... กรุณาเช็ค: ถ้าคิด "ลากิจ 1 (0.2) + ลาป่วย 2 (0.2)" ต้องได้ 4.6;
> ถ้าคิด "ลาป่วย 2 + สาย..." ไม่ตรง — จุดนี้ให้พี่ปกรณ์ยืนยันตัวเลขตัวอย่างอีกครั้ง)
