🎨 3. ฟีเจอร์หลัก

Dashboard ประกอบด้วย 5 แท็บ:

📊 1. สรุปโครงการ (Overview)

  • การ์ด KPI: ระยะเวลา, จำนวนงาน, งบประมาณ, หน่วยงานหลัก
  • กราฟความคืบหน้า (doughnut + bar chart)
  • สรุปงบประมาณ: วางแผน / ใช้จริง / คงเหลือ
  • งานสำคัญช่วงนี้

📅 2. แผนงาน (Plan)

  • Gantt Chart 6 สัปดาห์
  • ตาราง 17 งาน พร้อมสถานะ (รอเริ่ม / กำลังทำ / พักรอ / เสร็จ)
  • ปุ่ม 📝 บันทึกผล — บันทึกรายละเอียดการลงมือทำ
  • ปุ่ม 🔗 แนบลิงก์ — แนบเอกสาร/รูปถ่าย/รายงาน
  • ปุ่ม แก้ไข/ลบ — แก้ไขงานได้

🧯 3. ทะเบียนอุปกรณ์ (Equipment)

  • ตารางอุปกรณ์ดับเพลิง (ถัง, Detector, Sprinkler, Fire Pump)
  • สถานะ: ปกติ / หมดอายุ / ชำรุด / ซ่อมบำรุง
  • เพิ่ม/แก้ไข/ลบอุปกรณ์ได้

📞 4. ผู้ติดต่อ (Contacts)

  • เทศบาลพลับพลา
  • Supplier ถังดับเพลิง
  • ช่างซ่อมระบบดับเพลิง
  • ผู้รับผิดชอบภายใน

💰 5. งบประมาณ (Budget)

  • ตารางงบประมาณ 10 รายการ
  • คอลัมน์: ประมาณการ / ใช้จริง / วันที่ / หมายเหตุ
  • เพิ่ม/แก้ไข/ลบรายการได้
  • สรุปท้ายตาราง: งบรวม / ใช้จริง / คงเหลือ

📝 4. วิธีใช้งานแต่ละฟีเจอร์

🎯 4.1 การเปลี่ยนสถานะงาน

  1. ไปที่แท็บ 📅 แผนงาน
  2. คลิกที่ badge สถานะ (เช่น ⏳ รอเริ่ม)
  3. สถานะจะเปลี่ยนเป็น: รอเริ่ม → กำลังทำ → พักรอ → เสร็จ → วนกลับ
  4. ข้อมูลบันทึกอัตโนมัติ

📝 4.2 การบันทึกผลการปฏิบัติงาน

  1. ไปที่แท็บ 📅 แผนงาน
  2. คลิกปุ่ม 📝 บันทึกผล ในคอลัมน์ "ผลการปฏิบัติงาน"
  3. กรอก:
    • วันที่ลงมือทำ (เลือกจากปฏิทิน)
    • รายละเอียด (เช่น "ตรวจถังดับเพลิงทั้งหมด 20 ถัง — ใช้งานได้ 15 ถัง / หมดอายุ 5 ถัง")
  4. กด บันทึก
  5. ระบบจะบันทึก + เปลี่ยนสถานะเป็น "กำลังทำ" อัตโนมัติ
  6. สามารถบันทึกได้หลายครั้งต่องาน (ระบบเก็บประวัติ)

✅ ตัวอย่างการบันทึก:

งาน: สำรวจถังดับเพลิงพกพา

วันที่: 2026-11-02

รายละเอียด: ตรวจถังดับเพลิงพกพาทั้งหมด 20 ถัง

  • ใช้งานได้: 15 ถัง
  • หมดอายุ: 5 ถัง (ต้องส่งอัดใหม่)
  • ต้องซื้อเพิ่ม: 3 ถัง

🔗 4.3 การแนบลิงก์เอกสาร

  1. ไปที่แท็บ 📅 แผนงาน
  2. คลิกปุ่ม 🔗 แนบลิงก์ ในคอลัมน์ "แนบลิงก์"
  3. กรอก:
    • ชื่อลิงก์ (เช่น "รูปถังที่หมดอายุ", "รายงานสำรวจ")
    • URL (https://...)
  4. กด บันทึก
  5. ลิงก์จะแสดงเป็นปุ่มสีฟ้า คลิกเปิดแท็บใหม่ได้
  6. สามารถแนบได้หลายลิงก์ต่องาน

💡 ตัวอย่างลิงก์ที่ควรแนบ:

  • รูปถ่ายหน้างาน (Google Drive, Dropbox)
  • รายงานสำรวจ (PDF, Google Docs)
  • ใบแจ้งซ่อม/ใบเสนอราคา
  • SOP/คู่มือการใช้งาน

💰 4.4 การจัดการงบประมาณ

เพิ่มรายการงบประมาณ

  1. ไปที่แท็บ 💰 งบประมาณ
  2. กดปุ่ม + เพิ่มรายการ
  3. กรอก:
    • รายการ (เช่น "ค่าจ้างตรวจสอบระบบ")
    • จำนวน (เช่น 1)
    • ราคา/หน่วย (เช่น 10000)
    • ใช้จริง (เช่น 9500) — กรอกเมื่อจ่ายเงินแล้ว
    • วันที่ใช้ (เลือกจากปฏิทิน)
    • หมายเหตุ (เช่น "ใบเสร็จเลขที่ 12345")
  4. กด บันทึก

แก้ไข/ลบรายการ

  • แก้ไข: กดปุ่ม แก้ไข → แก้ไขข้อมูล → บันทึก
  • ลบ: กดปุ่ม ลบ → ยืนยัน

ดูสรุปงบประมาณ

ประมาณการรวม: ฿107,500

ใช้จริงรวม: (อัปเดตอัตโนมัติ)

คงเหลือ: งบประมาณ - ใช้จริง

สีเขียว = เหลือ / สีแดง = เกินงบ

🧯 4.5 การจัดการทะเบียนอุปกรณ์

เพิ่มอุปกรณ์

  1. ไปที่แท็บ 🧯 ทะเบียนอุปกรณ์
  2. กดปุ่ม + เพิ่มอุปกรณ์
  3. กรอก:
    • รหัส (เช่น T-005)
    • ประเภท (เช่น ถัง ABC 5 กก.)
    • ยี่ห้อ/รุ่น (เช่น Golden Lion)
    • จุดติดตั้ง (เช่น อาคารผลิต)
    • วันหมดอายุ (เช่น 2027-12-31)
    • สถานะ (ปกติ / หมดอายุ / ชำรุด / ซ่อมบำรุง)
    • การดำเนินการ (เช่น ส่งอัดใหม่)
  4. กด บันทึก

แก้ไข/ลบอุปกรณ์

  • กดปุ่ม แก้ไข หรือ ลบ ในคอลัมน์สุดท้าย

❓ 6. คำถามที่พบบ่อย

Q: ข้อมูลหายไปไหน?

A: ข้อมูลบันทึกใน 2 ที่:

  1. localStorage (เฉพาะเครื่องที่เปิด) — สำหรับ cache
  2. Google Sheets (รวมศูนย์) — สำหรับ sync ข้ามเครื่อง

ถ้าข้อมูลหาย ให้กดปุ่ม ☁️ เชื่อมต่อแล้ว แล้วเลือก โหลดจาก Cloud

Q: ทำไมคนอื่นไม่เห็นข้อมูลที่ฉันบันทึก?

A: ตรวจสอบว่า:

  1. Dashboard เชื่อมต่อ Google Sheets แล้ว (ดูปุ่มมุมขวาบน)
  2. กด บันทึก แล้ว (ไม่ใช่แค่กรอกข้อมูล)
  3. ให้คนอื่นกด 🔄 รีเซ็ตข้อมูล → โหลดจาก Cloud เพื่อดึงข้อมูลล่าสุด

Q: สามารถอัปโหลดไฟล์จริงได้ไหม?

A: ไม่ได้ — Dashboard รองรับเฉพาะ แนบลิงก์ (Google Drive, Dropbox, etc.)
ถ้าต้องการอัปโหลดไฟล์จริง ต้องใช้ฟีเจอร์อื่น (เช่น Google Forms + Drive)

Q: Export ข้อมูลเป็น Excel ได้ไหม?

A: ได้ 2 วิธี:

  1. กดปุ่ม 📤 Export JSON ใน Dashboard → ได้ไฟล์ JSON (เปิดใน Excel ได้)
  2. เปิด Google Sheet → File → Download → Excel (.xlsx)

Q: ใช้บนมือถือได้ไหม?

A: ได้ — Dashboard responsive รองรับมือถือ/แท็บเล็ต
แต่แนะนำใช้บน คอมพิวเตอร์ เพื่อความสะดวกในการกรอกข้อมูล
