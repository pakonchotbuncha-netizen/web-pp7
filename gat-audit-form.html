AU-1

หมวดที่ 1 — ข้อมูลและหลักฐาน (Data & Evidence)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU1 — การสอบทานความถูกต้องและความครบถ้วนของข้อมูลและหลักฐาน | วัตถุประสงค์: รับรองว่าตัวเลขในรายงานตรงกับข้อมูลต้นทาง มีเอกสารอ้างอิงครบ และสืบค้นที่มาได้

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
1.1ความตรงกันของตัวเลขในรายงานกับข้อมูลต้นทางสุ่มเทียบรายงานกับ source อย่างน้อย 5 รายการ
1.2ความครบถ้วนของเอกสารประกอบตรวจ checklist เอกสารตามรายการที่ขอ
1.3ความชัดเจนของที่มาและผังข้อมูลมีผังที่มา (ใครกรอก / จากระบบใด / เมื่อไร)
1.4การควบคุมเวอร์ชันและความน่าเชื่อถือของเอกสารตรวจวันที่ เวอร์ชัน ลายเซ็นอนุมัติ
AU-2

หมวดที่ 2 — ผลลัพธ์เทียบกับ OKR / KPI (Performance vs Targets)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU2 — การสอบทานผลการดำเนินงานเทียบกับ OKR / KPI / BSC | วัตถุประสงค์: รับรองว่าผลงานที่รายงานตรงตามความเป็นจริงและมีคำอธิบายช่องว่าง

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
2.1ความก้าวหน้าของวัตถุประสงค์และผลลัพธ์หลัก (OKR / KR)เทียบ KR รายข้อกับผลงานจริง
2.2ดัชนีชี้วัดสมดุลรายหน่วยธุรกิจ (BSC)สอบทานตัวเลข BSC ก่อนเสนอ OAC
2.3คำอธิบายช่องว่างระหว่างเป้าหมายและผลจริง (Gap Analysis)มีคำอธิบาย + แผนปิด gap หรือไม่
2.4ความเชื่อมโยงระหว่างผลงานกับหลักฐานผลงานทุกข้อต้องโยงถึงหลักฐาน AU-1 ได้
AU-3

หมวดที่ 3 — ความเสี่ยง (Risk)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU3 — การสอบทานทะเบียนความเสี่ยงและแผนบริหารความเสี่ยง | วัตถุประสงค์: รับรองว่าความเสี่ยงสำคัญมีเจ้าของ มีแผน และติดตามจริง

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
3.1ทะเบียนความเสี่ยงรายหน่วยธุรกิจมีทะเบียน ปรับปรุงล่าสุดเมื่อไร ครอบคลุมหรือไม่
3.2แผนบริหารความเสี่ยงระดับสูง (High Risks)ทุก High risk ต้องมีแผนใน 7 วัน
3.3การติดตามและรายงานความคืบหน้ามีรายงานรายสัปดาห์/เดือนหรือไม่
3.4ความเสี่ยงใหม่หรืออุบัติใหม่มีช่องทางแจ้ง risk ใหม่หรือไม่
AU-4

หมวดที่ 4 — การปฏิบัติตามกฎระเบียบและกระบวนการ (Compliance & Process, PM/WI)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU4 — การสอบทานการปฏิบัติตาม PM / WI และระเบียบภายใน | วัตถุประสงค์: รับรองว่าปฏิบัติตามขั้นตอน ไม่ข้ามขั้น กรณีเบี่ยงเบนมีเหตุผลและอนุมัติ

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
4.1การปฏิบัติตาม PM / WI ฉบับที่บังคับใช้สุ่มตรวจขั้นตอนเทียบ PM/WI
4.2การข้ามขั้นตอนหรือเบี่ยงเบนจากกระบวนการมีบันทึกขอเบี่ยงเบน + ผู้อนุมัติหรือไม่
4.3การปฏิบัติตามระเบียบภายในของกลุ่มบริษัทตรวจระเบียบที่เกี่ยวข้องกับเรื่องที่ตรวจ
4.4บันทึกการปฏิบัติงานและความสม่ำเสมอมีบันทึกต่อเนื่อง สืบค้นได้
AU-5

หมวดที่ 5 — กฎหมาย การปฏิบัติตามข้อกำหนด และภาษี 3 ประเทศ (LCT)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU5 — การสอบทาน LCT (Law + Compliance + Tax) และการเฝ้าระวัง Zero-breach | เจ้าภาพ: สาย LCT | เป้าหมาย: การละเมิด / ผิดพลาด / ผิดนัด = ศูนย์

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
5.1กฎหมายและใบอนุญาตรายประเทศ (ไทย / กัมพูชา / ลาว)ตรวจอายุใบอนุญาต + เงื่อนไขที่ต้องต่อ
5.2ภาษี การยื่นแบบ และการชำระ (3 ประเทศ)เทียบปฏิทิน LCT กับหลักฐานยื่นชำระ + เตือนล่วงหน้า ≥14 วัน
5.3คดีความและข้อพิพาท (ถ้ามี)มีแฟ้มคดี สถานะ ความเห็นทนาย แผนต่อไป
5.4เครือข่ายทนายความ 3 ประเทศและหน่วยงานภายนอกไทย: ทนายเจี๊ยบ / ทนายตุ๋ย • กัมพูชา: ทนายวีระบุตร • ลาว: (รอระบุ) + ผัง contact พร้อมเรียกใช้ใน 24 ชม.
5.5สรุป Zero-breach ประจำเดือนLaw-breach = 0 / Compliance-breach = 0 / Tax-breach = 0 (นับทุกครั้งไม่ว่ามีค่าปรับหรือไม่)
เส้นแดง LCT: breach เพียงหนึ่งครั้ง ให้ดำเนินการอย่างน้อยระดับ C2 ทันที • breach ซ้ำใน 6 เดือน ระดับ C3 • ปกปิดข้อมูล ระดับ C3–C4 (ตามกฎบัตรข้อ 8)
AU-6

หมวดที่ 6 — เทคโนโลยี ข้อมูล เงินและทรัพย์สิน (Tech / Data / Assets)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU6 — การสอบทานเทคโนโลยี ความปลอดภัยข้อมูล และการใช้เงินและทรัพย์สิน | ความถี่ขั้นต่ำ: ไตรมาสละหนึ่งครั้ง

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
6.1สิทธิการเข้าถึงระบบและข้อมูลตรวจ access log / สิทธิเกินจำเป็น / ผู้พ้นหน้าที่
6.2ความถูกต้อง ความปลอดภัย และการสำรองข้อมูลมี backup / แผนกู้คืน / เหตุข้อมูลรั่ว (ถ้ามี)
6.3การใช้เงินและทรัพย์สินอย่างคุ้มค่าเทียบอนุมัติจ่ายกับทะเบียนทรัพย์ / ความจำเป็น
AU-7

หมวดที่ 7 — บุคลากรและวัฒนธรรมองค์กร (เฉพาะกรณีได้รับมอบหมายจาก OAC)

ชื่อเรื่องที่ตรวจของแบบฟอร์ม: แบบฟอร์มย่อย F-AU7 — การสอบทานข้อร้องเรียน วินัย และการประเมินรอบด้าน | หมายเหตุ: ดำเนินการเมื่อมีเหตุอันควรหรือตามคำสั่ง OAC เท่านั้น

ข้อหัวข้อย่อยที่ตรวจวิธีตรวจ / หลักฐานที่ต้องแนบผลการตรวจระดับหลักฐานอ้างอิง + ข้อสังเกต
7.1ข้อร้องเรียนและเรื่องร้องทุกข์มีทะเบียนรับเรื่อง ตอบสนองใน 48 ชม.
7.2พฤติกรรม วินัย และกรณีทุจริต (ถ้ามี)สอบข้อเท็จจริงร่วมกับหน่วยที่ได้รับมอบหมาย
7.3การประเมินรอบด้าน (360°) ตามด่านสามผ่านข้อ 3ใจดีกับคน + เข้มงวดกับงาน (CC / credit)
