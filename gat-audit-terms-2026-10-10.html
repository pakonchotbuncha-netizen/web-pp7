📜 ร่างเงื่อนไขการตรวจสอบของ GAT — เพื่อให้ BU รับทราบ (Audit Charter v1.0)

หลักการ: ADM ทำ — GAT ตรวจ — OAC ตัดสิน  |  ตรวจแยกจากทำ มีหลักฐาน ไม่ใช้ความรู้สึก
เอกสารนี้เป็น ร่างให้เวที OA พิจารณา ก่อนประกาศใช้จริง — เมื่อเห็นชอบแล้วให้ผู้บริหารแต่ละ BU ลงนามรับทราบ
อ้างอิง: GAT Dashboard v1.0 (9 ต.ค. 69) • โครงสร้าง OAC / GA / BU / BMC (8 ต.ค. 69)

GAT: Audit พี่อ๊อด / พี่หนึ่ง / คุณบอล + LCT พี่ติ๋ม ผู้รับตรวจ: 4 BU + หน่วยกลาง + BMC ทุกชุด รายงานตรง OAC • 10 ต.ค. 2569 • แยกจาก Web PP7

ข้อ 1. วัตถุประสงค์ของการตรวจสอบ

  1. ให้ความมั่นใจ (Assurance) ว่าตัวเลข ผลลัพธ์ และรายงานของ BU ตรงความจริง มีหลักฐาน
  2. กันความเสียหายก่อนเกิด (Preventive) — เจอสัญญาณเสี่ยงเตือนก่อน ไม่รอให้พังแล้วค่อยแก้
  3. รักษา LCT Zero-breach — Law + Compliance + Tax = การละเมิด / ผิดพลาด / ผิดนัด = ศูนย์ ทุกเดือน 3 ประเทศ
  4. ทำให้มาตรฐานเดียวกันทุก BU (Consistency) — ตรวจด้วยเกณฑ์เดียว เทียบกันได้
  5. ตรวจแล้วงานต้องดีขึ้น — ไม่ใช่จับผิด แต่ชี้จุดอ่อน + แนะทางปิด + ติดตามจนปิด
สิ่งที่ GAT ไม่ทำ: ไม่บริหารงานแทน BU • ไม่สั่งงานข้ามหัว Core/BMC • ไม่ตัดสินใจแทน OAC • ไม่เปิดเผยข้อมูลลับนอกวงรายงาน

ข้อ 2. หัวข้อการตรวจสอบ (Audit Universe — 7 หมวด ครอบคลุมทุก BU)

ทุกครั้งที่ตรวจ ต้องระบุว่าตรวจหมวดไหน — ตรวจครบ 7 หมวด = ครอบคลุม 1 รอบปี

รหัสหมวดตรวจตรวจอะไรบ้าง (ตัวอย่าง)หลักฐานที่ BU ต้องมี
AU-1🔍 ข้อมูลและหลักฐานตัวเลขรายงานตรงกับต้นทางหรือไม่ / เอกสารครบ / ที่มาข้อมูลชัดSource + เอกสารอ้างอิง + ผังที่มา
AU-2🎯 ผลลัพธ์ vs OKR/KPIผลงานได้ตามที่รับปากหรือไม่ / BSC ราย BU ตรงจริง / ช่องว่างเท่าไรOKR/KPI sheet + ผลงานจริง + คำอธิบาย gap
AU-3⚠️ ความเสี่ยง (Risk)Risk สูงราย BU / แผนรับมือ / ใครเจ้าของ / ความคืบหน้าRisk register + แผน + สถานะ
AU-4📏 Compliance + Process (PM/WI)ทำตาม PM/WI หรือไม่ / ข้ามขั้นตอนหรือไม่ / ระเบียบภายในครบPM/WI ฉบับที่ใช้ + บันทึกการทำ + เหตุผลที่เบี่ยง
AU-5⚖️ LCT: Law + Compliance + Tax (3 ประเทศ)กฎหมาย / ใบอนุญาต / ภาษี / กำหนดยื่น / คดี-ข้อพิพาท / contact ทนาย-หน่วยงานปฏิทิน LCT + หลักฐานยื่นชำระ + แฟ้มคดี (ถ้ามี)
AU-6💻 Tech / Data / เงิน-ทรัพย์สินTech Audit: สิทธิ์เข้าถึง / ความถูกต้องข้อมูล / การใช้เงิน-ทรัพย์สินคุ้มค่าAccess log + ทะเบียนทรัพย์ + อนุมัติจ่าย
AU-7🤝 คนและวัฒนธรรม (สามผ่านด่าน 3)เฉพาะกรณี OAC สั่งตรวจ: พฤติกรรม / เรื่องร้องเรียน / 360° / ทุจริตบันทึก + ผลสอบข้อเท็จจริง (GAT ร่วม PAC ตามสั่ง)
ความถี่ขั้นต่ำ: AU-1~AU-4 ตรวจทุกรอบรายเดือน/ไตรมาสตามแผน • AU-5 (LCT) เฝ้าทุกเดือน + เตือนล่วงหน้า ≥14 วัน • AU-6 ไตรมาสละครั้ง • AU-7 เมื่อมีเหตุหรือ OAC สั่ง

ข้อ 3. สิทธิของ GAT (เพื่อให้ตรวจได้จริง)

  • ขอข้อมูล เอกสาร และการเข้าดูระบบที่เกี่ยวกับเรื่องที่ตรวจได้ — BU ต้องจัดให้ภายใน 3 วันทำการ (เรื่องด่วน LCT/Risk สูง ภายใน 24 ชม.)
  • สัมภาษณ์ผู้เกี่ยวข้อง + สุ่มตรวจหน้างานได้ โดยแจ้งล่วงหน้า ≥ 1 วัน (ยกเว้นทุจริต/เสี่ยงสูง ตรวจไม่แจ้งล่วงหน้าได้)
  • ออก Audit Report + กำหนดระดับ High Medium Low พร้อมวันครบกำหนดแก้ไข
  • ติดตาม (Follow-up) จนปิดประเด็น — ถ้าไม่คืบหน้ายกระดับรายงานตรง OAC ได้
  • เสนอใช้ Veto (Safety Gate สูงสุด 3 ครั้ง) ผ่าน OAC เมื่อพบว่าจะเกิดความเสียหายร้ายแรง

ข้อ 4. หน้าที่ของ BU (สิ่งที่ BU ต้องทำเมื่อถูกตรวจ)

  • แต่งตั้ง ผู้ประสานงานตรวจ (1 คน/BU) — รับแผนตรวจ ส่งข้อมูล นัดสัมภาษณ์
  • ส่งข้อมูลครบ ตรงเวลา — ถ้าส่งไม่ทันต้องแจ้งเหตุ + วันส่งใหม่ ก่อนครบกำหนด
  • รับ Audit Report ภายใน 3 วัน → ส่ง แผนแก้ไข (ใคร/ทำอะไร/เสร็จเมื่อไร) ภายใน 7 วัน (เรื่อง High) / 15 วัน (Med/Low)
  • ปิดประเด็นตามกำหนด — High 30 วัน / Med 60 วัน / Low 90 วัน (ขอขยายได้ 1 ครั้งพร้อมเหตุผล)
  • ห้ามปกปิด แก้ไข หรือทำลายหลักฐาน — พบเจอถือเป็นประเด็น High ทันที + รายงาน OAC

ข้อ 5. หน้าที่ของ GAT (ตรวจต้องเป็นธรรม)

  • แจ้งแผนตรวจล่วงหน้าเป็นรายเดือน — ไม่ตรวจนอกแผนยกเว้นเหตุฉุกเฉิน/OAC สั่ง
  • ทุกข้อสังเกตต้องมี หลักฐาน + เกณฑ์อ้างอิง (PM/WI/กฎหมาย/OKR) — ไม่มีหลักฐาน = ไม่ตั้งข้อสังเกต
  • ให้ BU ชี้แจงก่อนสรุป (Draft → ชี้แจง 5 วัน → Final) — บันทึกคำชี้แจงไว้ในรายงานเสมอ
  • รักษาความลับ — เปิดเผยเฉพาะใน Monthly Oversight Report ต่อ OAC และเจ้าของเรื่อง
  • GAT ตรวจผิด/ล่าช้าเอง → บันทึกไว้ในรายงานประจำเดือนของ GAT ต่อ OAC เช่นกัน (ตรวจคนตรวจ)

ข้อ 6. กระบวนการตรวจ (6 ขั้น — รอบรายเดือน)

1. แจ้งแผนต้นเดือน
GAT ส่งแผน + รายการขอข้อมูล
2. ส่งข้อมูลใน 3 วัน
BU ส่งผ่านผู้ประสานงาน
3. ตรวจ 7 หมวดตาม scope
สัมภาษณ์ + สุ่มตรวจ
4. Draft → ชี้แจง5 วัน
BU โต้แย้งพร้อมหลักฐานได้
5. Final + Oversightก่อนวันที่ 5 เดือนถัดไป
รวมเข้า OAC Report
6. Follow-up30/60/90 วัน
ปิด = Closed หลักฐานครบ

ข้อ 7. ความรับผิดชอบต่อผล — ด้านบวก (ทำดีต้องเห็น) 🌟

หลัก: ชมเป็นระบบ ไม่ใช่ชมปากเปล่า — ผูกกับ credit + โอกาส

ระดับเงื่อนไข (วัดได้)สิ่งที่ได้รับ (บวก)
B1 — ผ่านเกณฑ์ไม่มี High + ปิด Med/Low ทันกำหนด + LCT Zero-breach เดือนนั้นขึ้นกระดานเขียวใน Oversight Report + หนังสือชมเชยจาก OAC รายไตรมาส
B2 — ดีเด่นB1 ต่อเนื่อง 3 เดือน + มี Best practice ที่ถ่ายทอดให้ BU อื่นได้เป็น “BU ต้นแบบ” + ได้ถ่ายทอดในเวที OA + บันทึก credit สะสม (ใช้ประกอบสามผ่าน/เลื่อนบทบาท)
B3 — ยอดเยี่ยมB2 + Zero-breach ต่อเนื่อง 6 เดือน หรือปิด Risk สูงก่อนกำหนดจนเลี่ยงความเสียหายได้จริงOAC เสนอพิจารณารางวัล/งบพัฒนา/โอกาสนำโครงการสำคัญ + ประกาศเกียรติคุณประจำปี
GAT ด้านบวกด้วย: BU ประเมินประโยชน์ของ Audit ≥4/5 ต่อเนื่อง → GAT ได้รับ credit เช่นกัน — ตรวจดีต้องได้ดีเหมือนกัน

ข้อ 8. ความรับผิดชอบต่อผล — ด้านลบ (ทำพลาดต้องแก้ ไม่ใช่ลงโทษเอาสะใจ) ⚠️

หลัก: ไล่ระดับ แก้ที่ระบบก่อนคน — ซ้ำซากค่อยยกระดับ • ทุกขั้นมีหลักฐาน + สิทธิชี้แจง

ระดับเงื่อนไขผลที่ตาม (ลบ)ปลดล็อก
C1 — ตักเตือน + แก้ไขประเด็น Med/Low / ส่งข้อมูลช้าครั้งแรก / ปิดไม่ทันครั้งแรกมีเหตุผลบันทึกในรายงาน + แผนแก้ไขใหม่ (ขยายได้ 1 ครั้ง)ปิดตามแผนใหม่ = จบ ไม่ติดประวัติลบ
C2 — เฝ้าระวังเข้มมี High 1 เรื่อง / LCT breach 1 ครั้ง / ส่งข้อมูลช้าซ้ำ / ขอขยายบ่อยGAT ตรวจถี่ขึ้น (รายปักษ์) + รายงาน OAC ทุกครั้ง + BU รายงานความคืบหน้ารายสัปดาห์ปิด High ครบ + นิ่ง 2 เดือน = ปลด
C3 — รายงาน OAC พิจารณาHigh ≥2 เรื่องพร้อมกัน / LCT breach ซ้ำ / ปกปิดหลักฐาน / ไม่ทำแผนแก้ไขOAC พิจารณา: เปลี่ยนเจ้าของเรื่อง / ระงับอำนาจอนุมัติชั่วคราว / ใช้ Veto (นับ 1 ครั้ง) / สั่งสอบข้อเท็จจริงOAC สั่งปลดเมื่อเห็นว่าแก้จริง
C4 — ร้ายแรงทุจริต / ทำให้เสียหายร้ายแรง / LCT breach ร้ายแรง (คดี/ค่าปรับใหญ่/เสียใบอนุญาต)สอบวินัยตามระเบียบ + ดำเนินคดีตามกฎหมาย + รายงาน OAC ทันทีใน 24 ชม.ตามผลสอบ-คดี ไม่มีการปลดอัตโนมัติ
เส้นแดง LCT: breach ครั้งเดียว = อย่างน้อย C2 ทันที • breach ซ้ำใน 6 เดือน = C3 • ปกปิด = ข้ามไป C3/C4 ทันที — เพราะ LCT พลาดครั้งเดียวเสียหายทั้งกลุ่ม
กันกลั่นแกล้ง: BU โต้แย้งได้ทุกขั้น (ดูข้อ 9) — GAT ตั้งประเด็นโดยไม่มีหลักฐาน = GAT ถูกบันทึกความผิดพลาดเอง

ข้อ 9. สิทธิโต้แย้งและการอุทธรณ์ (Fairness)

  1. BU ชี้แจง Draft ได้ 5 วันทำการพร้อมหลักฐาน — GAT ต้องตอบเป็นลายลักษณ์อักษรทุกประเด็นที่โต้แย้ง
  2. ไม่เห็นด้วยกับ Final → อุทธรณ์ต่อ OAC ได้ใน 7 วัน — OAC ตัดสินเป็นที่สิ้นสุดในรอบนั้น
  3. ระหว่างอุทธรณ์ เรื่อง High/LCT ยังต้องทำแผนป้องกันชั่วคราวไปก่อน (กันเสียหายระหว่างรอตัดสิน)

ข้อ 10. การรับทราบ + รอบทบทวน

  • เอกสารนี้มีผลเมื่อ เวที OA เห็นชอบ + OAC อนุมัติ แล้วให้หัวหน้าแต่ละ BU + ผู้ประสานงานลงนามรับทราบ
  • ทบทวนทุก 6 เดือน หรือเมื่อโครงสร้าง/กฎหมายเปลี่ยน — GAT เสนอแก้ OAC อนุมัติ
  • ฉบับนี้: ร่าง v1.0 (10 ต.ค. 69) — รอฟีดแบ็กพี่ปกรณ์ + เวที OA ก่อนประกาศใช้
