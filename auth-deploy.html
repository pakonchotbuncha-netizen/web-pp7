🔐 Authorize Kilo — Google

กดปุ่มด้านล่างเพื่ออนุญาตให้ Kilo (AI ผู้พัฒนา Web PP7) เข้าถึง Google Workspace ของบัญชีนี้ เพื่อ อัปเดตและ Deploy ระบบ 3E3P + Web PP7 ให้อัตโนมัติ

✅ อ่าน/เขียน Google Sheets (ข้อมูล PP7)
✅ อ่าน/เขียน Google Drive (ไฟล์โปรเจกต์)
✅ จัดการ Google Apps Script (อัปเดตโค้ด + Deploy Web App)
🚀 กดเพื่อ Allow

หลังกด Allow แล้ว หน้าจะขึ้น error "can't be reached" — ให้คัดลอก URL ในแถบ address bar ส่งให้ Kilo (เฉพาะส่วนที่ขึ้นต้นด้วย http://127.0.0.1:43791/...)

⚠️ ใช้บัญชี Google ที่เป็นเจ้าของ Apps Script ของ Web PP7 (บัญชีเดียวกับที่ deploy ระบบ 3E3P)
