Logic เปิด–ปิดบริษัท

เปิดบริษัท → STATUS = ACTIVE
   → แสดงหน้า Web → เปิดตำแหน่งงานได้

ปิดบริษัท → STATUS = INACTIVE
   → ไม่แสดงหน้า Web
   → ห้ามสร้าง Job ใหม่
   → Jobs ที่เปิดอยู่ = CLOSED
   → ข้อมูล Application เดิมยังคงอยู่ (ห้ามลบ)
   → Audit Log บันทึกผู้ดำเนินการ

  • ปุ่ม "+ เพิ่มบริษัท" — ระบุ บริษัท / FU / สถานะ / ลำดับแสดงผล / วันที่เริ่มใช้ / วันที่ปิด
