Task 2 — Flow การสรรหา 10 ขั้นตอน · ข้อ 1 โครงสร้างองค์กร

  • คลิกเข้า "1. โครงสร้างองค์กร" แล้วเพิ่ม 4 เมนูย่อย:

├── DISPLAY_ORDER

BRANCH_MASTER
├── BRANCH_ID / COMPANY_ID (FK)
├── BRANCH_CODE / BRANCH_NAME
├── ADDRESS / PROVINCE / DISTRICT
├── STATUS / DISPLAY_ORDER / UPDATED_DATE

Logic เปิด–ปิดบริษัท

เปิดบริษัท → STATUS = ACTIVE
   → แสดงหน้า Web → เปิดตำแหน่งงานได้

ปิดบริษัท → STATUS = INACTIVE
   → ไม่แสดงหน้า Web
   → ห้ามสร้าง Job ใหม่
   → Jobs ที่เปิดอยู่ = CLOSED
   → ข้อมูล Application เดิมยังคงอยู่ (ห้ามลบ)
   → Audit Log บันทึกผู้ดำเนินการ

หน้า Admin: ⚙️ Admin > Master Data > บริษัท

  • ปุ่ม "+ เพิ่มบริษัท" — ระบุ บริษัท / FU / สถานะ / ลำดับแสดงผล / วันที่เริ่มใช้ / วันที่ปิด
  • การ์ดบริษัทแสดงสถานะ 🟢 เปิดใช้งาน พร้อมปุ่ม [แก้ไข] [ปิดบริษัท] → มี CONFIRM ก่อนปิด
  • ห้าม Delete บริษัทจริง — ใบสมัครเก่า/ประวัติต้องอ้างอิงบริษัทเดิมได้ (Soft-close เท่านั้น)

เมนู 1 · คีย์ขอโครงสร้าง (สิทธิ์: BMC / PAO / ผู้รับใช้ทีม)

→ คีย์ขอโครงสร้าง → ดึง Form → กรอกข้อมูล:

→ ส่งข้อมูลให้ PAO
