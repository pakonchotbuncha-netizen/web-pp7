Logic เปิด–ปิดบริษัท

เปิดบริษัท → STATUS = ACTIVE
   → แสดงหน้า Web → เปิดตำแหน่งงานได้

ปิดบริษัท → STATUS = INACTIVE
   → ไม่แสดงหน้า Web
   → ห้ามสร้าง Job ใหม่
   → Jobs ที่เปิดอยู่ = CLOSED
   → ข้อมูล Application เดิมยังคงอยู่ (ห้ามลบ)
   → Audit Log บันทึกผู้ดำเนินการ

  3. RBAC role "applicant": เห็นเฉพาะ ตำแหน่งงานว่าง · แบบฟอร์มสมัครงาน · แบบทดสอบ (ครั้งเดียว) · สถานะตัวเอง · Chatbot — มองไม่เห็นทุก tab ของ Web PP7 หลัก (ซ่อนเมนูภายในทั้งหมด)
  4. Dashboard ผู้สมัคร: แสดงสถานะรายขั้น + "ต้องทำอะไรต่อไป" (ส่งใบสมัคร/ทำแบบทดสอบ/ยืนยันนัดสัมภาษณ์/รอผล) — ดึงจาก Application Status กลาง NEW→HIRED (Task 3)
  5. Chatbot: FAQ อัตโนมัติ (ตำแหน่ง/เอกสาร/สถานะ) + AI ตอบจากข้อมูลตัวเอง (ผูกบัญชี) + ปุ่มส่งต่อ HR เมื่อตอบไม่ได้ + เก็บประวัติแชท/Audit Log
  6. แจ้งเตือนขาออกผ่าน Chatbot/อีเมล: สถานะเปลี่ยน · สิ่งที่ต้องทำต่อ · วันนัดสัมภาษณ์ (เชื่อม Notification Log ของ Task 3)
  7. Security: ผู้สมัครเห็น/ถามได้เฉพาะข้อมูลตัวเองเท่านั้น (ป้องกัน IDOR — ตรวจสิทธิ์ทุก query) · ห้ามโชว์ข้อมูลผู้สมัครคนอื่น/ข้อมูลภายใน
  8. เทส: ลงทะเบียนซ้ำ (อีเมล/เบอร์เดิม) · ทำแบบทดสอบครั้งที่ 2 ต้องถูกบล็อก · login ข้ามสิทธิ์เข้า tab ภายในต้องถูกบล็อก
การเชื่อมต่อกับ Task เดิม: ลงทะเบียน/บัญชีผู้สมัคร = ขยาย role "applicant" จาก Task 1 (RBAC) · ฟอร์มสมัคร = Task 3 · แบบทดสอบ 3 แบบ (ครั้งเดียว) = Task 4 · สถานะ/แจ้งเตือน = Notification Log ของ Task 3 · Chatbot ใช้ AI ตัวเดียวกับ Task 4/5 (คนละ prompt)
