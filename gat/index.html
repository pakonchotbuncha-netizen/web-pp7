การเชื่อมกับ Google Sheet BCT (บอร์ดทีม BU)

ทีม BU บันทึกรายการตรวจสอบบนชีท BCT (ชีท GAT_Registers, GAT_Entries, GAT_Issues) → ระบบนี้ดึงขึ้น Dashboard ผ่าน Google Apps Script Web App

  1. เปิด Google Sheet BCT → เมนู ส่วนขยาย (Extensions) → Apps Script
  2. วางโค้ดจากไฟล์ gat/gas-bct-bridge.js ทั้งไฟล์ → บันทึก
  3. เลือกฟังก์ชัน setupSheets → กด Run ครั้งเดียว (อนุญาตสิทธิ์) — จะสร้างชีท 3 ชีท + AuditLog อัตโนมัติ
  4. Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone → คัดลอก URL ลงในช่องด้านล่าง → บันทึก API URL
  5. กด 📥 Import จาก BCT — ข้อมูล live จะผสมกับ seed แล้วขึ้น Dashboard ทันที
นำเข้า/ส่งออก: นำเข้า = ชีท GAT_Registers/Entries/Issues → Dashboard · ส่งออก = Export CSV แถวล่างหรือปุ่ม Export ในแท็บ Registers (วางลงชีทได้เลย เพราะคอลัมน์ตรงกัน)
