🧪 ทดสอบระบบ PKG Recruitment

ทดสอบได้ทั้ง 2 มุมมองในหน้าเดียว พร้อมข้อมูลตัวอย่าง

📋 คำแนะนำการทดสอบ:

  1. เริ่มจากมุมมองผู้สมัคร → ลงทะเบียน → สมัครงาน → ทำแบบทดสอบ
  2. สลับไปมุมมอง HR → คัดกรอง → ส่งแบบทดสอบ → นัดสัมภาษณ์
  3. สลับกลับผู้สมัคร → ดูสถานะ → ทำแบบทดสอบ
  4. สลับไป HR → ดูผล → สรุปผล → นัดเริ่มงาน
